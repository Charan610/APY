# APY v1.4.12 — Tide

- New optional Tide theme, listed first in Settings → Theme.
- Navy, cream and coral atmosphere with four independently moving cloud layers and recessed vertical glass texture.
- Smoky glass cards, warm coral details and softer visual hierarchy.
- Existing theme preferences remain saved; Original, Pink and Silver are still available.
- Reduced-motion preferences disable cloud movement.

Install APY.apk over your existing app to keep local data.
